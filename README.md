## Projetos em destaque

### OrbitRisk-AI  
Projeto de Machine Learning voltado para análise de risco orbital, utilizando dados espaciais, pré-processamento, engenharia de atributos, treinamento de modelos, interpretabilidade com SHAP e aplicação em Streamlit.

### Computer Vision  
Projeto de classificação de imagens com redes neurais convolucionais, incluindo organização de dataset, treinamento, avaliação de modelo e aplicação demonstrativa.

### RPA Automation  
Automação desenvolvida com UiPath para captura, processamento e envio de informações por meio de formulário web.

### Big Data Pipeline  
Pipeline de dados com Apache Airflow, Docker e integração com banco de dados, realizando extração, transformação e carga de dados.

### Cloud & DevOps  
Projeto com foco em arquitetura cloud, segurança, organização de recursos e pipeline de CI/CD.
